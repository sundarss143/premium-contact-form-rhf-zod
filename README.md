# Premium Contact Form 🚀

A modern and responsive contact form built using **React**, **TypeScript**, **React Hook Form**, **Zod**, and **Tailwind CSS**.

This project demonstrates professional form handling, validation, API integration, and modern UI design practices.

---

# ✨ Features

- ✅ React Hook Form validation
- ✅ Zod schema validation
- ✅ Axios API integration
- ✅ Toast notifications
- ✅ Modern glassmorphism UI
- ✅ Responsive split-screen layout
- ✅ Tailwind CSS styling
- ✅ Lucide React icons
- ✅ Loading state handling
- ✅ Error messages
- ✅ Professional UI design

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/react-hook-form-zod-contact-form.git
```

---

## 2️⃣ Navigate Into Project

```bash
cd react-hook-form-zod-contact-form
```

---

## 3️⃣ Install Dependencies

```bash
npm install
```

---

## 4️⃣ Start Development Server

```bash
npm run dev
```

---
